# DLUTos

DLUTos is now kept as a RISC-V 64 kernel for QEMU `virt`.

## Build and Run

Required tools:

- Rust nightly from `rust-toolchain`
- `cargo`
- `cargo-binutils` / `llvm-tools-preview`
- `riscv64-linux-gnu-gcc`
- `qemu-system-riscv64`
- `mkfs.fat`
- util-linux `fdisk`

From the repository root:

```sh
make dlutos-build
make dlutos-run
```

The run target builds the RISC-V kernel, creates a FAT32 boot image from:

- `user-programs/busybox.static`
- `user-programs/init_script_riscv64.sh`
- `user-programs/tinyshell.c`

and attaches the Alpine ext4 image as the second virtio block device.

## Current Scope

- Target architecture: `riscv64`
- Platform: QEMU `virt`
- Boot image: FAT32 init image generated by `script/build-img.sh`
- External root filesystem: `alpine-linux-riscv64-ext4fs.img`

Removed development-only and non-RISC-V assets include old CI/editor config,
reference docs, report slides, test helper scripts, x86 user programs, and
LoongArch/x86 architecture code.
